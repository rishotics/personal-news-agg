🤖 Paper of the Day AI & Robotics Research

LLM

Weak-to-Strong On-Policy Distillation

Microsoft · ['Fangxu Yu', 'Zinan Lin', 'Xiaodong Liu', 'Weijia Xu', 'Michael Xu']
Why it matters
  1. Introduces a way to run on-policy distillation using a weaker teacher, flipping the usual assumption that teachers must be stronger than students.
  2. Novel because prior on-policy distillation methods cap student performance at teacher quality, making a strong-from-weak setup previously thought infeasible.
  3. Demonstrates that a student can exceed a weaker teacher's capability while still benefiting from dense token-level supervision on its own rollouts.
  4. Matters for labs like Microsoft, OpenAI, Google and Meta that rely on distillation pipelines to cheaply upgrade smaller deployed models.
  5. Changes distillation strategy going forward, since teams no longer need an expensive frontier model to meaningfully improve a strong base model via distillation.
