Agentic ESOpt: Fine-Tuning Long-Horizon LLM Agents with Minimal GPU Requirements

Independent/Academic (with DeepMind-affiliated co-author Yee Whye Teh) · Zhi Zheng, Rongsheng Chen, Yunpeng Ba, Zhenkun Wang, Yee Whye Teh
Why it matters
  1. Introduces Agentic ESOpt, an evolutionary-strategies alternative to RL for fine-tuning long-horizon LLM agents without backpropagation through entire trajectories.
  2. Directly attacks the core bottleneck of agentic RL: heavyweight backprop-based training stacks that struggle with branching interactions and sparse rewards.
  3. Claims fine-tuning long-horizon agents with minimal GPU requirements, a practically important cost and accessibility breakthrough if validated.
  4. Affects anyone building agentic LLM systems who currently faces prohibitive compute costs for RL-based post-training on multi-turn tasks.
  5. If the approach holds up, it could shift the default paradigm for agent fine-tuning away from PPO/GRPO-style RL toward gradient-free evolutionary optimization.
